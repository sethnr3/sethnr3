## 🚀 Featured Projects

### 🧠 A Dual System AI for Emotionally Intelligent Mental Health Support and Facial Mood Recognition

A real-time multimodal AI system that integrates text emotion recognition, facial emotion recognition, confidence-based late fusion, empathetic response generation, session memory, and crisis detection.

**Key Technologies:**
`Python` `React.js` `Node.js` `FastAPI` `Flask` `DistilRoBERTa` `VGG19` `ResNet18` `FLAN-T5` `Machine Learning` `Deep Learning` `NLP`

**Highlights:**

* Fine-tuned **DistilRoBERTa** for text emotion classification
* Developed facial emotion recognition models using **VGG19** and **ResNet18**
* Implemented confidence-based multimodal late fusion
* Integrated **FLAN-T5**, CBT-inspired response strategies, and crisis detection
* Achieved **73.7% text emotion classification accuracy**
* Achieved **67.31% facial emotion recognition accuracy**
